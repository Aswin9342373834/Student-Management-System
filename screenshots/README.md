# Application Screenshots Guide

This directory is prepared for capturing application screenshots for submissions and project reviews.

### Featured Screen Views:

1. **`01-dashboard.png`**: Complete Dashboard with dynamic statistics cards (Total, IT, CSE, ECE, MECH), Recharts department donut chart, year distribution bar chart, semester distribution (Semesters I through VIII), and recent student enrollments.
2. **`02-students-list.png`**: Students directory with comprehensive data table, custom badges for department, year, semester, contact links, and action buttons (View, Edit, Delete).
3. **`03-add-student.png`**: Add New Student form with real-time field validation (unique register number, valid email, 10-digit Indian phone number, department selection, and year-semester recommendations).
4. **`04-edit-student.png`**: Edit Student form pre-populated with existing student values and live validation.
5. **`05-delete-confirmation.png`**: Accessible confirmation modal preventing accidental deletions ("Delete Student? Are you sure you want to delete Arun Kumar? This action cannot be undone.").
6. **`06-search-filter.png`**: Real-time search query matching with combined filters (Department + Year + Semester) and active filter badge tags.
7. **`07-mobile-responsive.png`**: Mobile view featuring slide-out navigation drawer, responsive student cards, touch-friendly action buttons, and stacked metric cards.
